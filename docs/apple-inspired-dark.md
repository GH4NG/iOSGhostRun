# Apple 地图风格深色配色

这是一套参考 Apple 地图深色视觉设计的近似配色：冷调深灰陆地、深蓝水域、低饱和深绿公园，搭配柔和的道路和浅色标注。它不是 Apple 官方提供的地图样式或精确色值；实际 Apple 地图会随地区、版本、缩放级别与地图类型改变。

## 高德底图配色参考

已在高德发布「iOSGhostRun 冷灰夜色」，样式 ID 为 `10146c2104d182971b5311278a987024`。该样式只能与同账号的 JS API Key 配合使用，旧版用户升级时会保留选择；全新安装默认使用高德内置「极夜蓝」。可在[高德自定义地图编辑器](https://geohub.amap.com/mapstyle/index)中管理，或参考下表创建自己的样式。

| 地图元素 | 颜色 | 用途 |
| --- | --- | --- |
| 陆地、背景区域 | `#242628` | 与软件背景共用同一个冷调深灰 |
| 建筑物（专业版参考） | `#2E3135` | 当前免费编辑器不支持调整，未应用此色值 |
| 水域 | `#142A3D` | 保留明显但不刺眼的深蓝 |
| 公园、绿地 | `#263D32` | 保留自然的低饱和深绿 |
| 普通道路 | `#454B54` | 与背景区分，避免纯白道路 |
| 主干道路 | `#62656B` | 比普通道路略亮 |
| 高速道路 | `#9A8055` | 用柔和的暖色区分等级 |
| 地名、道路文字 | `#DDE3EB` | 提供清晰的文字对比 |
| 文字描边 | `#202327` | 保证文字在复杂路网中可读 |
| 水域文字 | `#7097BD` | 呼应蓝色水域 |
| 公园文字 | `#88B69A` | 呼应绿色公园 |

保留道路等级与 POI 图标的分类色，不使用灰度或整图反色滤镜。默认底图通过 SDK 的地图显示要素设置关闭建筑物显示。医院、商业、教育等区域也使用低饱和分类色；POI 文字保留蓝、绿、紫、暖棕等颜色，避免整张地图只有黑灰。

## 发布并应用

1. 登录高德，进入自定义地图编辑器，新建一个样式。可从深色模板开始，按上表逐类调整。
2. 预览不同区域与缩放级别，然后发布样式并取得样式 ID。高德 JS API 2.0 的文档要求先创建、编辑、发布，再通过 `amap://styles/样式ID` 加载。
3. 打开软件「设置 → 深色地图外观」，粘贴样式 ID 或完整 `amap://styles/…` 地址，点击「保存地图外观」。
4. 程序先验证样式 ID 是否能用当前 Key 读取；成功后在暗色模式下应用，失败则回退「极夜蓝」并提示。亮色模式仍使用标准底图。留空保存可移除自定义 ID。

跨账号使用时，可在 GeoHUB 开启“共享地图样式”，由对方复制进自己的账号并发布，然后使用新样式 ID。地图外观保存在 `map-appearance.json`，可在设置中导入／导出；其中不包含高德 Key 和安全密钥。表格和配色预览用于设计参考，不能直接作为高德样式文件导入。
